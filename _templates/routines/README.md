# 루틴

루틴은 **정해진 시간에 스킬을 자동으로 실행**하는 것이다.
스킬이 AI 단축키라면, 루틴은 "오전 9시에 그 단축키를 눌러라"라고 시키는 것이다.

루틴 목록의 원본은 `routines.json`이다. 대시보드도 이 파일을 읽는다.

## 기본 루틴

| 이름 | 일정 | 실행 스킬 |
|---|---|---|
| 데일리 모닝 브리핑 | 매일 {{BRIEFING_TIME}} | morning-briefing |
| 노트 Inbox 정리 | 매주 일요일 21:00 | (제안만, 파일은 옮기지 않음) |
| 주간 스킬 점검 | 매주 금요일 18:00 | skill-improver (제안만) |

## 등록하는 법

설치 직후에는 루틴이 **등록되어 있지 않다**. 아래 말을 Claude에게 하면 등록해 준다.

> routines.json의 루틴을 예약 작업으로 등록해 줘. 등록한 뒤 각 루틴에 scheduledTaskId와 registered 날짜를 적어 줘.

## 단계별 실행 방법

### 초급: Claude 데스크톱 앱의 예약 작업

- Code 탭 왼쪽의 **예약됨** 메뉴에서 확인하고 고칠 수 있다.
- 한계: **PC와 데스크톱 앱이 켜져 있을 때만** 실행된다. 꺼져 있었다면 다음에 앱을 켤 때 실행된다.

### 중급: 24시간 켜진 컴퓨터

PC가 꺼져 있어도 돌게 하려면, 남는 PC(또는 클라우드 서버)를 24시간 켜 두고 거기에 Claude Code를 설치한다.
작업 파일은 **Syncthing** 같은 동기화 도구로 두 컴퓨터 사이에 맞춘다.

- 동기화할 폴더: `{{ROOT}}`, `{{VAULT}}`, `~\.claude\skills`
- 24시간 PC에서는 Windows 작업 스케줄러로 아래 명령을 실행한다.

```bat
cd /d "{{ROOT}}"
claude -p "morning-briefing 스킬을 실행해서 오늘의 브리핑을 만들고 저장해 줘."
```

### 고급: 클라우드 에이전트

- Claude Code의 클라우드 예약 에이전트(`/schedule`)를 쓰면 PC 없이 돌릴 수 있다.
- 다만 클라우드에서는 로컬 파일을 바로 읽을 수 없으므로, 노트를 GitHub 저장소나 Google Drive로 옮겨야 한다.

## 주의

- 예약 작업의 실제 프롬프트는 `~\.claude\scheduled-tasks\<ID>\SKILL.md`에 따로 저장된다. `routines.json`을 바꾸면 그 파일도 함께 고쳐야 한다.
- 사람이 보지 않는 시간에 도는 루틴에는 되돌리기 어려운 행동(파일 이동·삭제, 메일 발송)을 맡기지 않는다. "제안만" 하게 만든다.
