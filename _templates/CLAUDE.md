# {{TITLE}}

이 폴더는 {{OWNER}}의 모든 AI 업무를 한곳에서 지휘하는 **관제탑**이다.
자료를 여기에 복사하지 않는다. 자료는 원래 자리에 두고, 이 폴더는 **어디에 무엇이 있는지 안내**한다.

작업을 시작하기 전에 아래 순서를 따른다.

1. 요청이 어느 업무 분야인지 판단한다.
2. 아래 표에서 해당 **길잡이 파일**을 먼저 읽는다.
3. 길잡이 파일이 가리키는 원본 폴더·문서·스킬로 이동해서 작업한다.
4. 새 자료를 만들었다면, 해당 길잡이 파일에 링크 한 줄을 추가한다.

---

## 업무 분야별 길잡이

| 분야 | 이럴 때 | 먼저 읽을 길잡이 |
|---|---|---|
| 전체 지도 | 어디서부터 볼지 모를 때 | `guides/00_전체지도.md` |
| 콘텐츠 | 글, 영상, SNS 작업 | `guides/10_콘텐츠.md` |
| 지식 | 노트 찾기, 저장 | `guides/20_지식.md` |
| 개발 | 앱·도구·자동화 프로젝트 | `guides/30_개발.md` |
| 스킬 | 어떤 스킬을 쓸지, 스킬 만들기·고치기 | `guides/40_스킬.md` |
| 루틴 | 예약 작업, 매일 자동 실행 | `routines/README.md` |
| 익스텐션 | 메일·캘린더·노션 등 외부 연결 | `guides/50_익스텐션.md` |

## 작업 원칙

- 한국어로 답한다. 결론을 먼저 말하고, 이유는 그다음에 설명한다.
- 초보자도 이해할 수 있게 설명하고, 결과물은 복사해서 바로 쓸 수 있는 형태로 준다.
- 같은 요청을 두 번 받았다면, 그 작업을 스킬로 만들자고 제안한다.
- 원본 자료를 지우거나 옮기기 전에는 반드시 확인을 받는다.
- 메일 발송, 게시, 결제처럼 밖으로 나가는 행동은 초안까지만 만들고 확인을 받는다.
