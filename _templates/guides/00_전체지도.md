# 전체 지도

{{TITLE}}은 4단계(스킬 · 세컨드 브레인 · 루틴 · 익스텐션) 구조를 따른다.

| 단계 | 의미 | 이 시스템에서의 위치 |
|---|---|---|
| 1. 스킬 | 반복 업무를 AI 단축키로 만든다 | [[40_스킬]] · `.claude/skills/` |
| 2. 세컨드 브레인 | AI가 자료를 스스로 찾게 한다 | `CLAUDE.md` → `guides/` → 원본 자료 |
| 3. 루틴 | 정해진 시간에 스킬을 자동 실행한다 | `routines/` |
| 4. 익스텐션 | 외부 서비스와 도구를 연결한다 | [[50_익스텐션]] |
| + 대시보드 | 위 네 가지를 한 화면에서 본다 | `dashboard/index.html` |

## 길잡이 목록

- [[10_콘텐츠]]: 글, 영상, SNS
- [[20_지식]]: 노트 보관소
- [[30_개발]]: 앱·도구 프로젝트 폴더
- [[40_스킬]]: 스킬 목록과 관리 방법
- [[50_익스텐션]]: 연결된 서비스

## 길잡이 파일 쓰는 법

- 길잡이 파일은 **주제별 링크 모음**이다. 내용을 길게 쓰지 않고, 어디로 가야 하는지만 적는다.
- 링크는 `[[노트이름]]`(노트) 또는 `` `C:\경로` ``(폴더·파일)로 적는다. 대시보드는 이 두 형식을 읽어서 연결 수를 센다.
- 한 길잡이가 50줄을 넘으면, 하위 길잡이로 나눈다.
- 새 분야가 생기면 `guides/60_새분야.md`처럼 번호를 붙여 추가하고, `CLAUDE.md` 표에 한 줄 넣는다.
