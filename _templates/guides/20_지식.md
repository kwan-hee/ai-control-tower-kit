# 지식 길잡이 (세컨드 브레인)

## 원본 위치

`{{VAULT}}`

## 폴더별 용도

노트 보관소의 폴더 구조에 맞게 고친다. 처음이라면 아래 구조로 시작해도 된다.

| 폴더 | 용도 |
|---|---|
| `00_Inbox` | 아직 분류하지 않은 새 자료 |
| `10_Context` | AI가 먼저 읽을 나에 대한 맥락 |
| `20_Projects` | 진행 중인 프로젝트 기록 |
| `50_Outputs` | 완성된 결과물 |
| `60_Lessons` | 실패와 해결 기록 |
| `70_Hubs` | 주제별 허브 (길잡이 역할) |
| `91_Daily` | 일일 노트 (모닝 브리핑도 여기에 저장) |

## 저장 규칙

- 새 주제가 생기고 노트가 5개를 넘으면, `70_Hubs`에 허브를 하나 만들고 이 표에 추가한다.

## 찾는 순서

1. 이 길잡이와 해당 허브를 읽는다.
2. 그래도 없으면 노트 보관소 전체를 파일 이름과 본문으로 검색한다.
