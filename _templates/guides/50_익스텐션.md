# 익스텐션 길잡이

에이전트가 실제 업무를 하려면 외부 서비스와 연결되어 있어야 한다.
연결 방법은 쉬운 순서대로 **커넥터 → MCP → CLI → API**이다.

## 지금 연결된 것

Claude 데스크톱 앱의 **설정 → 커넥터**에서 연결한 뒤, 아래 표에 적는다.

| 분야 | 연결 |
|---|---|
| 메일 · 일정 | (예: Gmail, Google Calendar) |
| 문서 · 지식 | (예: Notion, Google Drive) |
| 브라우저 | (예: Claude in Chrome) |

## 새 연결이 필요할 때

- connector-finder 스킬에게 "○○를 연결하고 싶어"라고 말한다.
- 맞는 것이 없다면 직접 만든다.
