# 커넥터 찾기

## 목표

필요한 외부 서비스를 가장 쉬운 방법으로 연결한다. 쉬운 순서는 **커넥터 → MCP → CLI → API**이다.

## 순서

1. **필요 확인**: 무엇을 하고 싶은지 한 문장으로 정리한다. (예: "매일 유튜브 채널 조회수를 가져오고 싶다")
2. **이미 있는지 확인**: `{{ROOT}}\guides\50_익스텐션.md`와 현재 세션에서 쓸 수 있는 도구를 확인한다. 이미 있으면 바로 사용법을 알려 준다.
3. **찾기** (위에서 찾으면 아래는 건너뛴다):
   1. Claude 데스크톱 앱의 커넥터 목록 (mcp-registry 검색)
   2. MCP 서버: 웹에서 "<서비스명> MCP server" 검색, GitHub README 확인
   3. CLI: 공식 CLI 도구가 있는지 확인
   4. API: 공식 API 문서와 키 발급 방법 확인
4. **비교**: 후보를 최대 3개까지 아래 표로 비교한다.

   | 후보 | 종류 | 난이도 | 비용 | 할 수 있는 일 | 출처 |
   |---|---|---|---|---|---|

5. **추천**: 하나를 추천하고, 설치·연결 순서를 번호로 적는다.
6. **기록**: 연결이 끝나면 `guides/50_익스텐션.md` 표에 한 줄 추가한다.

## 안전 원칙

- 공식 저장소나 많이 쓰이는 저장소만 추천한다. 별이 적고 출처가 불분명한 저장소는 위험하다고 알린다.
- API 키나 비밀번호는 사용자가 직접 입력하게 안내한다. 대신 입력하거나 채팅에 적게 하지 않는다.
- 설치 명령은 실행 전에 무엇을 하는지 설명하고 확인을 받는다.
